What it does

Everything a quote needs, and nothing you have to learn.

Set your price list once. After that most quotes are a few clicks and a client name.

Your price list, built in

Pick line items from a list you control. Costs and working days come with them.

Packages in one click

Totals in Rands, live

Quote becomes invoice

Save a client once

Clean A4 PDF

South African terms already written

Stays on your machine

Clients and numbers save to plain files in the folder. Nothing is uploaded anywhere.

Running it

Three steps, about five minutes.

It is a small set of files and one command. There is nothing to install beyond Python.

1

Download the folder

Clone it, or use the green Code button on GitHub and choose Download ZIP.

git clone https://github.com/greycollectionsa/Invoice-Joy.git
2

Start it up

Open the folder in a terminal and run the server. It uses only what Python ships with.

python3 server.py
3

Open it and quote

Go to the address below in your browser. Type straight onto the page.

http://localhost:8000/Invoice.html

You need Python 3. Macs and most Linux machines already have it. On Windows, install it from python.org and tick Add Python to PATH during setup.

Before you download

What it does not do.

Worth knowing up front, so you can walk away now rather than in ten minutes.

× Accounting

No bank feeds, no VAT returns, no ageing reports. It builds documents. Your accountant still does the books.

× Team sync

One person, one computer. Two people cannot work on the same client list at the same time.

× A mobile app

It runs in a desktop browser. You can quote from a laptop on site, but not from your phone.
